# Architecture decision records

One Markdown file per decision: `NNNN-short-title.md` (e.g. `0001-mission-control-v1-snapshot.md`).

Each record has four short sections: **Context**, **Decision**, **Consequences**, **Status** (proposed / accepted / superseded). Keep it under one page, link the issue and add the decision to the decision log.

Technical decisions are approved by Simon or a supervisor in the PR (architecture v0.5, section 10.1).
