# Portals

React + TypeScript (Vite) apps for the people who use Rainmaker. Not Maven modules.

| Portal | Users | Main use cases |
|---|---|---|
| Publisher portal (editorial view) | Editors / ad ops | Approve, reject or correct AI suggestions; block categories; switch off (UC-05, UC-15) |
| Publisher portal (sales) | Publisher sales | Advertisers, offers and results (UC-08, UC-09) |
| Management dashboard | Publisher management | Revenue, traffic, quality and risks (UC-14) |
| Admin portal | Rainmaker admin, central sales, finance | Onboarding, policy, pilot mode, settlement (UC-01, UC-13, UC-16) |

Swedish and English from day one with react-i18next – no hard-coded texts. Login with Amazon Cognito.

One folder per portal is added when work on it starts.
